Demo disposition — one message

A real run disposes of everything past retention, which on a demo-length policy is the whole corpus. This generates a single throwaway message, waits out the retention period configured for its type, and then deletes that one message — through the same ingestion, archive and delete path, so a legal hold covering it still blocks the deletion with 409.

The countdown keeps running while you are on other screens, and across a page reload, so you can start it here and watch the dashboard's message count drop when it fires.
